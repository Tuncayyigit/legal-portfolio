# Legal Ops Portfolio – Tuncay Yiğit Gürtunca

This repository showcases fictional, de-identified examples of my work and thinking as a junior technology-facing lawyer.  
All materials are generic and do not derive from any client, company, or real case.

## What’s inside

- **templates/**
  - `ip_takedown_notice_template.md`  
    Sample IP takedown notice for digital platforms (Apple App Store / Google Play Store style).
  - `cease_and_desist_letter_template.md`  
    Generic cease-and-desist letter for IP or unfair competition scenarios.

- **checklists/**
  - `cross_border_data_transfer_checklist.md`  
    Practical checklist for assessing cross-border data transfers (KVKK / GDPR-inspired, jurisdiction-agnostic).
  - `mobile_app_privacy_compliance_checklist.md`  
    High-level checklist for privacy and data protection issues in mobile app products.

- **notes/**
  - `ip_enforcement_workflow_note.md`  
    Short outline of a basic IP enforcement workflow for a content/app company.

## Focus areas

- Tech-driven legal operations  
- IP enforcement and platform compliance  
- Privacy and data governance  
- Practical, product-facing documentation for internal stakeholders

Again, everything in this repository is **fictional and generic**, prepared solely to demonstrate drafting style, structure, and legal-ops thinking.
